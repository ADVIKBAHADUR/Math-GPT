RECIPROCAL-BASED DIVISION APPROACH - VISUAL OVERVIEW
====================================================

TRADITIONAL APPROACH (Not Working Well):
-----------------------------------------
Stage 1: Learn Division Directly
  Input:  8/4=?
  Model:  Has to compute division → 2.0
  Issue:  Division is hard for neural networks!


NEW APPROACH (Reciprocal-Based):
---------------------------------

┌─────────────────────────────────────────────────────────────────┐
│ STAGE 0: RECIPROCAL FOUNDATION (New!)                          │
├─────────────────────────────────────────────────────────────────┤
│  Goal: Memorize reciprocals from 1/1 to 1/100                  │
│                                                                 │
│  Training Examples:                                             │
│    1/1=1.0    1/2=0.5    1/3=0.3    1/4=0.2    1/5=0.2         │
│    1/6=0.2    1/7=0.1    1/8=0.1    1/9=0.1    1/10=0.1        │
│    ... (continues to 1/100=0.0)                                 │
│                                                                 │
│  Why it works:                                                  │
│    ✓ Only 100 values to memorize                               │
│    ✓ All are 1 decimal place (simple)                          │
│    ✓ Deterministic (no computation needed)                     │
│    ✓ Model learns lookup table                                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ STAGE 1+: DIVISION AS MULTIPLICATION (Updated!)                │
├─────────────────────────────────────────────────────────────────┤
│  Goal: Use learned reciprocals to solve divisions              │
│                                                                 │
│  Preprocessing happens BEFORE model sees it:                    │
│                                                                 │
│    Original:  8/4                                               │
│         ↓                                                       │
│    Lookup:    1/4 = 0.2  (from reciprocal table)               │
│         ↓                                                       │
│    Convert:   8*0.2                                             │
│         ↓                                                       │
│    Model:     8*0.2=1.6  (just multiplication!)                │
│                                                                 │
│  More Examples:                                                 │
│    6/2  →  6*0.5  =  3.0                                        │
│    10/5 →  10*0.2 =  2.0                                        │
│    9/3  →  9*0.3  =  2.7                                        │
│    12/4 →  12*0.2 =  2.4                                        │
│                                                                 │
│  Why it works:                                                  │
│    ✓ Model already knows multiplication                        │
│    ✓ Model already knows reciprocals from Stage 0              │
│    ✓ Division = Multiplication × Reciprocal                    │
│    ✓ Easier cognitive load on the model                        │
└─────────────────────────────────────────────────────────────────┘


KEY INSIGHT:
------------
  Division: a/b = a × (1/b)
           ↓        ↓     ↓
         Hard   Easy   Memorized
                      (from Stage 0)


PRECISION TRADE-OFF:
--------------------
  1 decimal place precision:
    • 1/3 = 0.333... → stored as 0.3
    • 1/4 = 0.25 → stored as 0.2
    • 8/4 = 2.0 → becomes 8*0.2 = 1.6 (slightly off)
    
  This is acceptable because:
    ✓ Makes the problem tractable
    ✓ Model can learn patterns
    ✓ Can be improved later if needed
    ✓ Still better than model failing completely


CURRICULUM SEQUENCE:
--------------------
Stage 0: Reciprocals      → Learn 1/1 to 1/100
Stage 1: Division         → Actually multiplication (8*0.2)
Stage 2: Multiplication   → Pure multiplication
Stage 3: Addition         → Pure addition
Stage 4: Subtraction      → Pure subtraction
Stage 5: Mult+Div Mix     → Uses reciprocals for division
Stage 6: Add+Sub Mix      → Mixed operations
Stage 7: All Ops (1-dig)  → All operations, divisions use reciprocals
Stage 8+: 2-digit ops     → Same pattern with larger numbers
